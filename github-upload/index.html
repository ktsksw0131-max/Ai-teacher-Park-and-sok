02

AI로 기획하기

머릿속 아이디어를 AI와 함께 구체적인 글과 콘텐츠 기획안으로 빠르게 정리합니다.

03

플로우(Flow)로 영상 제작

기획한 내용을 바탕으로 AI 영상 제작 툴 플로우를 활용해 나만의 영상을 직접 완성합니다.
